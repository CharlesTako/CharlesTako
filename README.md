## Hello,
This is my time series forecasting project.

## Project Objective
This group project aims to develop, evaluate, and present time series forecasting models. Each group will select an approved dataset and apply both:

An Exponential Smoothing model
An ARIMA model
The final goal is to compare model performance and present the most effective forecasting approach.

## Data Requirements
Unemployment datset used was retrieved from

[FRED (Federal Reserve Bank of St. Louis)](http://research.stlouisfed.org/fred/)
Forecasting Models

Analysis included the following:

An appropriate exponential smoothing model
An ARIMA model
At least 10% of data must be held out as a test (validation) set
Evaluation and report forecast accuracy metrics
model selection decisions
